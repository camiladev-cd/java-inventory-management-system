# Java Inventory Management System

A console-based inventory management system built in Java using Object-Oriented Programming principles.

## Features

- Add products
- List products
- Search products by ID
- Delete products
- Product categories using Enums
- Product stock management
- Input validation for price and stock

## Technologies

- Java
- OOP (Object-Oriented Programming)
- ArrayList
- Enums
- Scanner

## Project Structure

```text
src/com/camila/dev/
├── Main.java
├── Product.java
├── ProductManager.java
└── Category.java
```

## Concepts Practiced

- Encapsulation
- Classes and Objects
- Collections
- Enums
- Constructors
- Getters and Setters
- Separation of Concerns
- CRUD Operations
- Input Validation
- Console Applications
